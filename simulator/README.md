# Симулятор LED-матрицы 32×8

Показывает эффекты прошивки (`../led_matrix_weather_clock/fx_*.cpp` и соседние файлы) в браузере.
Работает **тот же самый C++ код**, что и на ESP8266: он собирается в WebAssembly,
а вместо Arduino и FastLED подставляются заглушки из папки `shim/`.

## Как смотреть
Открой `simulator.html` двойным кликом. Интернет и сервер не нужны.

- Список эффектов: клик или стрелки ← →.
- Пауза — пробел, один кадр — `.`, перезапуск — `R`, скорость ×¼…×16.
- Справа задаются условия: ветер, сезон, текст бегущей строки, дата и время.
- Наведи мышь на светодиод: покажет координаты, номер в ленте и цвет.
- Под матрицей — ток эффекта при выбранной яркости и приглушит ли его лимит FastLED.

## Как пересобрать после правки эффектов
Двойной клик по `build.bat` (или `python build.py`).
Один раз нужен компилятор: `python -m pip install ziglang`.

## Файлы
| Файл | Что это |
|---|---|
| `simulator.html` | Готовая страница (создаётся сборкой) |
| `viewer.html` | Шаблон страницы |
| `sim_main.cpp` | Подключает эффекты из скетча и отдаёт кадры браузеру |
| `tools/golden.mjs`, `tools/golden.json` | Эталон: все эффекты кадр в кадр (проверка «ничего не сломалось») |
| `shim/Arduino.h`, `shim/FastLED.h` | Заглушки Arduino и FastLED для ПК |
| `build.py`, `build.bat` | Сборка |
| `tools/snapshot.mjs` | Снимает кадры всех эффектов в одну PNG (для проверки) |
| `tools/stars_longrun.mjs` | Многочасовой прогон «Звёздной ночи»: не пустеет ли небо |
| `tools/seasons_sheet.mjs` | Сцены во все четыре сезона на одной картинке |
| `tools/font_sheet.mjs` | Весь шрифт бегущей строки на одной картинке |

## Чем симулятор отличается от матрицы
- Цвета на мониторе и на светодиодах выглядят по-разному. Галочка
  «Как видит глаз» приближает картинку к тому, что видно вживую.
- Wi-Fi, погода, кнопка и веб-интерфейс не симулируются, только эффекты.
- Скорость и память ESP8266 не учитываются: если эффект тормозит на
  матрице, в симуляторе этого видно не будет.
